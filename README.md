# wx视频电话自动接听

家里老人不会接wx视频电话，用别的监控设备延迟又太高，所以想到用自动接听wx的方式，让家人随时能通过wx视频看到老人的情况。

## 开箱即用（推荐）

项目里已经附带打包好的安装包 **`小新_v1.0.10.apk`**，不需要电脑、不需要安装 AutoX.js，直接安装就能用：

1. 把 `小新_v1.0.10.apk` 发到手机（wx"文件传输助手"、QQ 或数据线都可以）
2. 在手机上点击安装（如提示"未知来源应用"，允许安装即可）
3. 首次打开后授予权限（见下方 [手机设置](#手机设置)）：
   - **无障碍服务** — 必须
   - **悬浮窗权限** — 必须
   - **通知权限** — 必须
4. 打开 APP，点击 **启动**，即可自动接听wx视频电话

> 如果不需要修改代码，看到这里就可以了。下面的步骤是给需要自己修改、构建项目的开发者看的。

## 准备工作（开发者）

### 手机要求

- Android 手机
- 安装 AutoX.js（[下载地址](https://github.com/autox-community/AutoX_aiselp/releases)）
- 安装wx

### 电脑要求

- 安装 Node.js（16 以上版本）
- 安装 VS Code

## 使用步骤（开发者）

### 第一步：下载项目

把项目下载到电脑，然后用 VS Code 打开项目文件夹。

### 第二步：安装依赖

在 VS Code 终端里运行：

```
npm install
```

### 第三步：构建项目

```
npm run build-autox
```

构建完成后会生成 `dist-autox` 文件夹和一个 `dist-autox.zip` 压缩包。

### 第四步：传到手机

**方法一：wx/QQ 文件传输（最简单，不用数据线）**

1. 构建后在项目文件夹找到 `dist-autox.zip`
2. 通过wx"文件传输助手"或 QQ 把 `dist-autox.zip` 发到手机
3. 手机上收到文件后，用 AutoX.js 打开：
   - 打开 AutoX.js → 点击右上角 **+** 号 → **导入** → 选择收到的 zip 文件
4. 导入后在 AutoX.js 里点击 `start-ui.js` 运行

**方法二：数据线**

1. 用数据线连接手机和电脑
2. 把 `dist-autox` 文件夹复制到手机的 AutoX.js 脚本目录（通常是 `内部存储/脚本/` 或 AutoX.js 里显示的主目录）

**方法三：npm 命令（手机和电脑在同一 WiFi 下）**

1. 手机打开 AutoX.js，在侧边栏打开 USB 调试
2. 电脑终端运行：

```
npm run save-autox
```

3. 输入手机屏幕上显示的 IP 地址

### 第五步：手机上运行

1. 手机打开 AutoX.js
2. 找到 `dist-autox` 文件夹
3. 点击 `start-ui.js` 运行

### 第六步：打包成独立 APK（可选）

在 AutoX.js 的项目列表中找到该项目，点击打包图标即可生成独立 APK（就是项目里附带的 `小新_v1.0.10.apk` 的来源），打包后安装即可脱离 AutoX.js 独立运行。

## 手机设置

### 必须开启的权限

在手机 **设置** 里找到 AutoX.js（或已安装的 `小新` APP），开启以下权限：

- **无障碍服务** — 必须，用来模拟点击
- **悬浮窗权限** — 必须，显示控制界面
- **通知权限** — 必须，用来监听wx来电通知
- **后台弹出界面** — 建议开启
- **自启动** — 建议开启，开机后自动运行

### wx设置

- 确保wx的 **通知权限** 已开启
- 建议把wx设为 **允许后台活动**，防止系统杀掉wx进程

## 坐标配置（可选）

脚本默认会自动检测接听按钮的位置。如果自动检测不准，可以手动设置坐标。

### 自动计算不准时怎么获取坐标

不同手机分辨率、系统版本、微信版本的来电界面可能不一样。如果脚本日志里显示已经点击了，但实际没有点到横幅、小窗或接听按钮，就用开发者模式手动确认坐标。

1. 打开手机 **设置 → 关于手机**，连续点击 **版本号** 7 次，开启开发者模式
2. 回到 **设置 → 系统/更多设置 → 开发者选项**，打开 **指针位置**
   - 不同品牌入口可能略有不同，可以在设置里直接搜索 **开发者选项** 或 **指针位置**
3. 让家人给老人打一个wx视频电话
4. 屏幕顶部会显示当前手指触摸位置的坐标，通常能看到类似 `X: 540 Y: 2100`
5. 用手指按住要点击的位置，记下顶部显示的 **X** 和 **Y** 值
6. 在脚本界面对应位置填入坐标，点 **保存配置**
7. 保存后再打一次视频电话测试；如果仍然偏一点，可以把 X/Y 每次微调 10-30 像素再试

有两个坐标可以设置：

| 坐标 | 说明 |
|------|------|
| **横幅坐标** | 来电时顶部小横幅的位置（如果来电是全屏则不需要设置） |
| **小窗坐标** | 操作手机后，来电横幅变成右上角小窗时的位置 |
| **接听坐标** | 全屏来电时绿色接听按钮的位置 |

不填则自动检测，填了就用手动坐标。每次点击会自动加 ±5 像素的随机偏移，模拟手指点击。配置保存后重启脚本也会保留。

## 常见问题

**问：脚本运行后没反应？**

检查无障碍服务是否开启。在手机 **设置 → 无障碍** 里找到 AutoX.js 并开启。

**问：能检测到来电但不接听？**

自动检测的按钮位置可能不准。按上面的方法手动设置坐标。

**问：手机重启后脚本不运行了？**

在 AutoX.js 设置里开启 **自启动**，或者每次开机后手动运行一次脚本。

**问：老人不小心关掉了脚本怎么办？**

可以教老人看到 AutoX.js 的悬浮窗图标就点一下，或者帮老人设置 AutoX.js 开机自启动。

### 模拟器开发相关

**问：用模拟器测试，`npm run save-autox` 输入模拟器 IP（如 10.0.2.15）后报 `连接设备失败：connect ETIMEDOUT 10.0.2.15:9317`？**

`10.0.2.15` 是模拟器内部 NAT 网络的虚拟 IP，电脑无法直接访问。解决方法是用 adb 做端口转发：

```bash
# 1. 安装 adb（只需一次）
brew install --cask android-platform-tools

# 2. 连接模拟器（不同模拟器 adb 端口不同）
adb devices                  # 已列出设备则跳过下一行
adb connect 127.0.0.1:16384  # MuMu: 16384 / 夜神: 62001 / 雷电: 5555

# 3. 把电脑 9317 端口转发到模拟器
adb forward tcp:9317 tcp:9317
```

然后运行 `npm run save-autox`，IP 输入 **`127.0.0.1`** 即可。注意模拟器里的 AutoX.js 需先在侧边栏开启 HTTP 服务（9317 端口）。端口转发在模拟器重启后会失效，需要重新执行第 2、3 步。

**问：打包的 APK 打开后是空白页 / 界面不是自动接听面板？**

APK 里 webview 是用 `loadLocalFile`（file:// 协议）加载页面的，有两个要求（本项目已配置好，改动 `vite.config.ts` 时别删掉）：

1. `base: './'` — 资源必须用相对路径，否则 `/assets/xxx.js` 加载不到
2. `viteSingleFile()` 插件 — 把 JS/CSS 内联进单个 index.html，否则 `<script type="module">` 外链脚本在 file:// 下会被 CORS 拦截，页面 JS 不执行

改完前端代码后，重新 `npm run save-autox` 保存到设备，再在 AutoX.js 里重新打包 APK 覆盖安装。建议先在 AutoX.js 项目列表里点「运行」确认界面正常，再打包。

**问：Mac 终端提示 `command not found: npm`？**

npm 是通过 nvm 安装的，新终端需要先加载 nvm 并切换版本：

```bash
source $(brew --prefix nvm)/nvm.sh
nvm use 20
```
